# ISR 蛛行 · 城市搜救模拟器

第三人称六足救援机器人驾驶探索模拟器。场景设定为暴雨后的临川市 7 号街区，视觉方向参考 `E:\root\aim\几猫国产3A大作_V1_2.html`，机器人结构与任务能力依据 ISR 蛛行项目 PPT。

## 渲染架构

- WebGPU-first 渲染，浏览器不支持时自动降级到 WebGL2。
- Three.js TSL 节点后处理：GTAO、Bloom、速度模糊、SMAA、动态胶片颗粒和电影调色；WebGPU 路径额外启用 SSR。
- 高分辨率程序化 PBR 材质、湿地面法线、积水波纹、体积灯光与城市辉光。

## 运行

直接双击根目录的 `index.html` 即可离线运行。Three.js、CSS、脚本和全部场景资源均已内联，不依赖 CDN。

开发模式：

```powershell
npm run dev
```

重新构建单文件版本：

```powershell
npm test
npm run build
```

## 操作

- `W/S`：前进 / 后退
- `A/D`：差动转向
- `Shift`：加速
- `Space`：紧急驻停
- `G`：三角步态 / 波动步态
- `R` 或鼠标右键：按住扫描
- `F`：启动 / 停止自动寻人
- `Tab`：打开 / 关闭雷达页
- `E`：确认并上传证据
- 鼠标拖动：环绕镜头
- 滚轮：镜头距离
- `H`：操作说明
- `M`：声音开关
- 双击画面：请求鼠标锁定

## 已实现

- 按 PPT 白色高端样机方向重建的小型 ISR 机体：低矮中央机身、顶部感知塔、侧提手、设备舱、六条三关节腿和 18 个可动关节。
- 约 0.56 米机身、0.98 米腿展，可通过净高约 0.53 米的坍塌夹层。
- 髋关节与机身同高，足端挂点和脚掌姿态分离校正，支撑相与摆动相均保持在真实地面以上。
- Rapier 3D 碰撞层：建筑、车辆、树木、石块、家具和街道道具均有碰撞代理。
- 机体使用体积检测，髋节、膝节、胫节和脚掌逐段扫掠，镜头有独立遮挡通道。
- `P` 可切换碰撞线框调试视图。
- 两连杆逆运动学、三角步态、波动步态、差动转向与足端压力反馈。
- 起步/制动惯性、机身倾斜、足端落地镜头脉冲、液压与伺服音效。
- 雨夜城市、湿沥青、水洼、楼体窗光、断电线缆、车辆、公交残骸、消防梯、街道路障、锥桶、垃圾箱和降雨粒子。
- 底层商铺使用程序化室内贴图，加入货架、灯光、破碎玻璃和室内剪影。
- 地面加入裂缝、油污、轮胎印和纸屑贴花，建筑加入真实窗格、挑檐、壁柱、空调外机和屋顶设备。
- Bloom 后处理、电影色调、雨夜天空、湿地反光、涟漪、体积灯光和程序化建筑立面。
- 九类传感器面板、移动/驻停双模式、扫描进度和三项证据融合。
- 三处搜索区、卧姿模拟受困人员、温度阈值探测、雷达联系人、疑似目标确认和任务结算。
- `F` 自动寻人：A* 规划路径、自动驶向搜索区并驻停扫描，发现疑似人员后等待人工确认。
- `Tab` 雷达页：显示机器人朝向、障碍、低矮通道、扫描扇区和已检测的人体热源。
- 桌面 HUD、启动画面、操作帮助、静音与重新开始流程。

## 仿真边界

本项目是交互演示，不是实体救援性能证明。未接入 STM32/ESP32、WebSocket、真实 YOLO 或实物传感器；搜救目标、热源、人体存在和声音数据均为场景内模拟值。
